# Mini Tokyo Drive

ブラウザで遊べる東京ドライブシミュレータ(MapLibre + three.js)。
ミニ・スクーター・自転車・空飛ぶミニ(シークレット)で東京を走り、デリバリーアプリ風の配達ゲームも楽しめます。

▶ プレイ: https://ms06ytz.github.io/mini-tokyo-drive/

- 音楽プレイヤーは 📁 ボタンで自分の PC の MP3/MP4 を選んで再生します(曲は同梱していません)。
- 地図: OpenFreeMap / © OpenStreetMap contributors、ルート: OSRM、住所検索: 国土地理院・Nominatim
- 詳しい仕様は [mini-tokyo-drive-handoff.md](mini-tokyo-drive-handoff.md) を参照。
